Веб-интерфейс для подачи заявок на транскрибацию
Тестовое задание на позицию разработчика

Технологический стек
1. Платформа: .NET 10 (ASP.NET Core)
2. UI-фреймворк: Blazor Server, MudBlazor
3. ORM: Entity Framework Core
4. База данных: SQLite 
5. Аутентификация: Кастомный Scoped-сервис (сессии в памяти)

Функционал
Для пользователя (user1, user2):
1. Авторизация в системе.
2. Подача заявок на транскрибацию (выбор типа заявки, указание спикеров, прикрепление файлов).
3. Условная валидация (если выбран тип "с протоколом", поле протокола становится обязательным).
4. Просмотр списка своих заявок и их деталей.
5. Добавление терминов в глоссарий.

Для администратора (admin):
1. Просмотр всех поступивших заявок и терминов.
2. Изменение статусов (заявки: "Выполнено", глоссарий: "Принято/Отклонено").
3. Просмотр детальной информации по каждой заявке.

Как запустить проект
1. Установите [.NET 10 SDK](https://dotnet.microsoft.com/) и Visual Studio 2026.
2. Склонируйте репозиторий.
3. Откройте решение (`.sln`) в Visual Studio.
4. Откройте консоль диспетчера пакетов (Package Manager Console) и примените миграции для создания БД:
   Update-Database
5. Нажмите F5

Используемые для авторизации данные
1. логин - admin, пароль - 123 (Администратор)
2. логин - user1, пароль - 123 (Обычный пользователь)
3. логин - user2, пароль - 123 (Обычный пользователь)
