Веб-интерфейс для подачи заявок на транскрибацию
Тестовое задание на позицию разработчика

Технологический стек
Платформа: .NET 10 (ASP.NET Core)
UI-фреймворк: Blazor Server, MudBlazor
ORM: Entity Framework Core
База данных: SQLite 
Аутентификация: Кастомный Scoped-сервис (сессии в памяти)

Функционал
Для пользователя (user1, user2):
Авторизация в системе.
Подача заявок на транскрибацию (выбор типа заявки, указание спикеров, прикрепление файлов).
Условная валидация (если выбран тип "с протоколом", поле протокола становится обязательным).
Просмотр списка своих заявок и их деталей.
Добавление терминов в глоссарий.

Для администратора (admin):
Просмотр всех поступивших заявок и терминов.
Изменение статусов (заявки: "Выполнено", глоссарий: "Принято/Отклонено").
Просмотр детальной информации по каждой заявке.

Как запустить проект
1. Установите [.NET 10 SDK](https://dotnet.microsoft.com/) и Visual Studio 2026.
2. Склонируйте репозиторий.
3. Откройте решение (`.sln`) в Visual Studio.
4. Откройте консоль диспетчера пакетов (Package Manager Console) и примените миграции для создания БД:
   Update-Database
5. Нажмите F5
